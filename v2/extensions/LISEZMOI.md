# Extensions (couche 3)

Ce qui se branche sur les points d'extension publics de BlockNote : typographie française ; depuis le 11/11/2026, le style « exposant » (`exposant/`) et le bloc « Table des matières » (`tableDesMatieres/`) ; depuis le 12/11/2026, les blocs « Titre » et « Sous-titre » (`titres/`). Chaque extension est écrite comme si elle devait partir en amont ; son apparence est définie dans `design/`. Rempli à l'étape 4.
