# Scénarios de l'étape 5, « Relecture » (2026-11-08)

- Auteur : Claude.
- Statut : proposés à l'ouverture ; à ajuster après l'arbitrage du plan (`docs/v2-etape-5-plan.md`).

| Couche | Scénario |
|---|---|
| T1 | capacités par rôle pour les suggestions, les commentaires et l'historique (domaine) ; date d'accès et début de l'historique |
| T3 | permissions de chaque branche par rôle (route interne) ; routes des commentaires : créer, répondre, résoudre, supprimer le sien, supprimer celui d'un autre (éditeur seulement) ; refus pour un rôle sans droit ; données piégées dans le corps d'un commentaire |

| T5 | éditeur : accepter, refuser, tout accepter, tout refuser ; rechargement ; deux navigateurs convergent |
| T5 | commentaires : un correcteur commente ; un lecteur selon l'arbitrage ; un éditeur supprime le fil d'un autre |
| T5 | historique : liste, comparaison, version nommée, retour arrière par l'éditeur ; un correcteur arrivé tard ne voit pas l'historique d'avant |
